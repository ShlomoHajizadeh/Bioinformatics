\# Reynolds Boids Model - 2D \& 3D



Implementation of Craig Reynolds' flocking model (boids) in 2D and 3D toroidal domains.



\## Features



\- Two species of agents:

&#x20; - \*\*Species 1 (Boids)\*\*: Follow avoidance, alignment, and cohesion rules

&#x20; - \*\*Species 2 (Avoidance Agents)\*\*: Follow only avoidance rule with smaller minimum distance

\- Toroidal (periodic) boundary conditions

\- Configurable parameters

\- Visualization and animation capabilities

\- Metrics and diagnostics for analysis
