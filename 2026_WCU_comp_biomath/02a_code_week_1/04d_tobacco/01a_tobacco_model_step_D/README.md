\# Tobacco ecosystem model - Version A



Minimal trophic model for:

\- tobacco plants

\- adult moths

\- caterpillars

\- big-eyed bug predators



\## Included processes

\- day/night cycle

\- moth movement

\- egg laying at night

\- egg hatching after a delay

\- caterpillar plant damage

\- predator movement toward prey

\- predator consumption of caterpillars

\- plant recovery



\## Run

```bash

python main.py
