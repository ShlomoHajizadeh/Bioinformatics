\# Auanema 3D Simulation



A beginner-friendly modular Python project for simulating the population dynamics of Auanema nematodes in continuous 3D space.



\## Features



\- Continuous 3D domain

\- Point agents

\- Three reproductive types:

&#x20; - male

&#x20; - female

&#x20; - hermaphrodite

\- Nearest-neighbor targeted movement for males

\- Simple probabilistic reproduction

\- Age-based death

\- Population time-series plots

\- Optional 3D scatter animation



\## Run



```bash

python main.py
