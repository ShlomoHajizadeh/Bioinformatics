# AlphaFold Database (AlphaFold DB)

The **AlphaFold Database** (co-developed by DeepMind and EMBL-EBI) is an open-access repository containing over 200+ million 3D protein structure predictions generated by AlphaFold.

## Key Features
- **Coverage**: Whole-proteome predictions across model organisms, human proteome, and Swiss-Prot/UniProtKB entries.
- **Confidence Metrics**:
  - **pLDDT (predicted Local Distance Difference Test)**: Per-residue confidence (0–100).
  - **PAE (Predicted Aligned Error)**: Inter-domain orientation and rigid-body distance uncertainty in Ångströms.
- **Programmatic Access**: REST API access allowing direct retrieval of `.pdb`, `.cif`, and PAE JSON matrices via UniProt accession IDs.

## Related Concepts & Tools
- [[Biopython]] — used to parse coordinate files and calculate structural metrics.
- [[Miyazawa-Jernigan-Potentials]] — empirical scoring of residue contacts.
