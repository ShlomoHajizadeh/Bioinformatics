# Rosalind Bioinformatic Problem Platform

**Rosalind** ([rosalind.info](https://rosalind.info)) is an educational and benchmarking platform for learning computational biology through algorithmic problem solving.

## Core Problem Implementations in Starter Kit
- **`DNA`**: Counting DNA Nucleotides (Nucleotide frequency histograms).
- **`RNA`**: Transcribing DNA into RNA ($T \to U$ conversion).
- **`PROT`**: Translating RNA into Protein (ORF translation with standard codon table).
- **`GC`**: Computing GC-Content (Windowed and sequence-wide percentage).
- **`HAMM`**: Counting Point Mutations (Hamming distance calculation).
