# GEO & TCGA

**NCBI GEO (Gene Expression Omnibus)** and **TCGA (The Cancer Genome Atlas / NCI GDC)** represent the foundational public data repositories powering secondary data analysis in modern computational oncology.

## Core Features & Access
- **NCBI GEO**: Curated repository for high-throughput gene expression data (microarrays, bulk RNA-seq, scRNA-seq). Accessed via accession tokens (`GSE...`, `GSM...`).
- **TCGA / GDC Data Portal**: Multimodal genomic, transcriptomic, epigenomic, and clinical outcome dataset spanning 33 human cancer types (e.g. BRCA, LUAD, COAD) with longitudinal patient survival metadata.
